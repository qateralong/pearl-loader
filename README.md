# Pearl Loader

Server-side Fabric mod: ender pearls keep their chunks loaded for stasis chambers, leave with the owner on logout and return on login.

## Features

- Thrown ender pearls keep their chunks loaded, so stasis chambers work.
- Pearls leave with their owner on logout and come back on login.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
